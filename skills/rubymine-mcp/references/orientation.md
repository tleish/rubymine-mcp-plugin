# Project orientation



```bash
mcp rubymine get_project_dependencies '{"projectPath": "<project_root>"}'
mcp rubymine get_project_modules '{"projectPath": "<project_root>"}'
mcp rubymine get_repositories '{"projectPath": "<project_root>"}'
```
No other required args. Useful for a first orientation pass in an unfamiliar area of a large/multi-module/multi-repo project.
